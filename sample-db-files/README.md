# Complex Fintech Database Test Pack

10 database artifacts:

- 4 MariaDB/MySQL `.sql`
- 2 PostgreSQL `.sql`
- 2 Drizzle ORM `.ts`
- 2 DBML `.dbml`

The schema models identity/KYC, accounts, wallets, currencies, FX, cards,
merchants, payment methods, transfers, transactions, double-entry ledger,
fees, refunds, chargebacks, settlements, invoices, subscriptions, loans,
credit scoring, limits, fraud/risk, audit, webhooks, API keys, notifications,
support tickets and reconciliation.

All fixtures are synthetic.
